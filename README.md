# 🔐 Secure File Storage and Sharing System (Mini-Vault)

Клиент жағында шифрланатын қауіпсіз бұлттық файл сақтау және алмасу жүйесі.

## 🎯 Жобаның мақсаты
Пайдаланушылардың файлдарын серверге жүктемес бұрын клиент құрылғысында сенімді шифрлау, деректердің тұтастығын тексеру және файлдарды басқа қолданушылармен қауіпсіз түрде бөлісу.

## 🛠 Негізгі технологиялар мен криптография
* **Тіл және фреймворк:** Java 17+, Spring Boot, Maven/Gradle
* **Дерекқор:** PostgreSQL
* **Криптография (JCA):**
  * **AES-GCM:** Файлдарды клиент жағында шифрлау.
  * **PBKDF2:** Пайдаланушы құпиясөзінен шифрлау кілтін генерациялау.
  * **SHA-256:** Файлдардың тұтастығын (integrity) тексеру.
  * **RSA:** Кілт алмасу және файлдарды басқа қолданушылармен қауіпсіз бөлісу.

## ⚙️ Орнату және іске қосу (Installation)
1. Репозиторийді клондау:
   ```bash
   git clone https://github.com
   cd secure-file-vault
   ```
2. Дерекқор баптауларын `src/main/resources/application.properties` файлында көрсету.
3. Жобаны жинау және серверді іске қосу:
   ```bash
   mvn clean install
   mvn spring-boot:run
   ```

## 💻 Қолдану мысалы (Usage)
1. Пайдаланушы жүйеге тіркеліп, кіреді.
2. Клиенттік қосымшада файл таңдалып, құпиясөз арқылы **PBKDF2 + AES-GCM** көмегімен локальді түрде шифрланады және серверге жүктеледі.
3. Файлды әріптеспен бөлісу үшін оның **RSA ашық кілті** қолданылып, мерзімі шектелген сілтеме жасалады.

## 🛡️ Қауіпсіздік ескертпесі (Security Notice)
* **Zero-Knowledge принципі:** Шифрлау кілттері мен пайдаланушы құпиясөздері серверде сақталмайды.
* Құпиясөз жоғалған жағдайда шифрланған файлдарды қалпына келтіру мүмкін емес.
* Репозиторийде API кілттері, құпиясөздер және жеке сертификаттар сақталмайды.
