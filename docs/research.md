# Research: Қауіпсіз файл сақтау және алмасу жүйесі (Secure File Vault)

## 1. Жобаның өзектілігі мен мақсаты
Қазіргі бұлттық қоймаларда деректер көбінесе сервер жағында шифрланады, бұл сервер әкімшілеріне немесе шабуылдаушыларға файлдарды оқуға мүмкіндік береді. Бұл жоба **Zero-Knowledge** (нөлдік білім) қағидатына негізделген: файлдар серверге жіберілмес бұрын клиент құрылғысында шифрланады.

## 2. Жүйе акторлары (Actors)
* **Пайдаланушы (User):** Жүйеге тіркеледі, файлдарды локальді түрде шифрлап серверге жүктейді, өз файлдарын дешифрлап алады, файл нұсқаларын басқарады және басқа қолданушыларға уақытша сілтеме арқылы бөліседі.
* **Администратор (Admin):** Жүйе қауіпсіздігін бақылайды, аудит журналын (Audit Log) тексереді және пайдаланушылардың қолжетімділік құқықтарын басқарады.

## 3. Функционалдық және қауіпсіздік талаптары
* **Құпиялылық (Confidentiality):** Файлдарды **AES-GCM (256-bit)** алгоритмімен шифрлау.
* **Кілт генерациясы:** Пайдаланушы құпиясөзінен **PBKDF2WithHmacSHA256** арқылы криптографиялық кілт алу.
* **Тұтастық (Integrity):** Жүктелген және түсірілген файлдардың өзгермегенін **SHA-256** хэш сомасы арқылы тексеру.
* **Қауіпсіз бөлісу (Key Exchange):** Файл кілтін алушының **RSA** ашық кілтімен шифрлау және мерзімі шектелген сілтемелер (Expiring Links) жасау.
* **Аудит (Accountability):** Барлық маңызды әрекеттерді (жүктеу, өшіру, бөлісу) аудит журналына тіркеу.
